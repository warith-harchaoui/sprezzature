# Command-line interface (CLI) → web graphical user interface (GUI) — `sprezzature-cli-gui`

Wrap an existing command-line tool in a single-page vanilla-JavaScript (JS) + Tailwind GUI. It reads the CLI's argparse / Click / clap / cobra parser and maps sub-commands and flags to forms, segmented controls, file inputs, and streaming log panels.

This is the human landing page. It points to the three places that hold the
detail; nothing is duplicated here.

- **What it is & what activates it:** [`sprezzature-cli-gui/SKILL.md`](../sprezzature-cli-gui/SKILL.md)
  (the agent-facing spec: purpose, trigger phrases, full flag surface).

  `sprezzature-cli-gui`.
