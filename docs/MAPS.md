# Maps — `sprezzature-maps`

Draw numbers attached to real places on real geography: a world choropleth
(each country filled by a value, Equal Earth projection), a layered
areas-of-control situation map for any region, and an accumulation map where
point events draw the land with no coastline drawn. Every plate is
hand-authored Scalable Vector Graphics (SVG), and a static audit of eleven
rules reads the finished plate back to check that it says how it was made.

This is the human landing page. It points to the three places that hold the
detail; nothing is duplicated here.
