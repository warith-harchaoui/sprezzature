# Markdown → website — `sprezzature-publish`

Turn a folder of Markdown into a static site: per-page meta tags (Open Graph, Twitter, Schema.org), a favicon / progressive web app (PWA)-icon set from one logo, robots.txt / sitemap / llms.txt / feeds, plain-language rewrites, and local text-to-speech (TTS) narration.

This is the human landing page. It points to the three places that hold the
detail; nothing is duplicated here.

- **What it is & what activates it:** [`sprezzature-publish/SKILL.md`](../sprezzature-publish/SKILL.md)
  (the agent-facing spec: purpose, trigger phrases, full flag surface).
- **Run it:** [`EXAMPLES.md`](../EXAMPLES.md) has a copy-paste recipe for
  `sprezzature-publish`.
- **Go deeper:** [`sprezzature-publish/references/`](../sprezzature-publish/references/): meta tags, site indexes, plain language, narration.
