# Markdown → website — `sprezzature-publish`

Turn a folder of Markdown into a static site: per-page meta tags (Open Graph, Twitter, Schema.org), a favicon / progressive web app (PWA)-icon set from one logo, robots.txt / sitemap / llms.txt / feeds, plain-language rewrites, and local text-to-speech (TTS) narration. For a site that already exists, search, generative and answer engine optimisation (SEO, GEO, AEO) ordered by its call to action (CTA): it asks which CTA the site is for, builds the FAQ the site lacks from its own pages, and reports money pages first.

This is the human landing page. It points to the three places that hold the
detail; nothing is duplicated here.

  (the agent-facing spec: purpose, trigger phrases, full flag surface).

  `sprezzature-publish`.
