# Developer dependencies for working on the sprezzature skill.
#
# Install:
#   pip install -r requirements-dev.txt
#
# That is the whole install. The second line used to point at a per-skill
# runtime requirements file; no skill folder in this repository ships one any
# more — the model-backed scripts left with their bricks — so the line named a
# file nobody could install.

# Fast deterministic test suite under tests/
pytest>=8.0.0

# tests/conftest.py imports best_engine_ai_helper.safety to neutralise the
# NSFW scan that chat() has run on every call since 1.4: left alone it
# downloads 270 MB of classifier into every test run. The LLM/VLM scripts that
# called chat() themselves have left with their bricks, so this is now the one
# consumer in this repository — and it is a test-time import, which is why the
# dependency belongs here and not in pyproject.toml.
best-engine-ai-helper>=1.4

# Logging and the small filesystem primitives, for two scripts that already
# import it: `web/tools/render_gallery.py` and `sftp/sync_web.py` both open on
# a bare `import os_helper as osh` and call `init_logging` / `info` / `warning`
# / `error` throughout. Neither guards the import, and nothing declared it —
# so a fresh clone with this file installed got a ModuleNotFoundError from the
# first line of the gallery renderer, and from the one script whose job is to
# put the site online. Declaring what is already imported is the whole change.
#
# Here and not in pyproject.toml, deliberately. `[tool.setuptools] packages`
# ships `sprezzature/` and the ten skill folders; `web/tools/` and `sftp/` are
# in neither, so no installed copy of this package can reach these scripts. A
# base dependency would instead pull os-helper's `>=3.10,<3.14` onto this
# repository's own `requires-python = ">=3.10"`, which would then be a promise
# of a Python the dependency excludes — the defect
# `tests/test_no_brick_promises_a_python_its_dependencies_exclude.py` guards.
# The CI matrix is 3.10 / 3.11 / 3.12, well inside that window.
#
# Its two siblings in these scripts are NOT here, and the difference is the
# guard at the call site, not the weight: `sftp/sync_web.py` wraps
# `import sftp_helper` in a try/except that prints the pip line, and
# `tests/test_no_film_is_voiced_by_a_retired_engine.py` reaches
# `speaker_helper` through `pytest.importorskip`. Installing them would add 15
# and 23 packages — numpy, scipy and soundfile among them — to every job of
# every push.
#
# Half of that reasoning expired on 2026-10-31 and is corrected here rather
# than left standing. It used to end "to wake one test that skips anyway on a
# `web/video` no clone has". The clone has `web/video` now — the 22 caption
# tracks and their voice stamps are committed — so that test no longer skips
# for want of a directory, only for want of `speaker_helper`. The remaining
# argument is the 23 packages, which is a cost and not a reason, and it is a
# decision rather than a fact: the guard it would wake is the one that catches
# a track still carrying a voice the router no longer chooses.
# Plancher à 4.0.0 le 2026-11-01, et c'est une décision à deux moitiés.
#
# La 4.0.0 d'os-helper est une release majeure parce qu'elle a cessé de mentir :
# `hashfile` ne rend plus de digest pour un fichier qu'il n'a pas lu (il
# hachait le chemin en silence), un répertoire est refusé, `hashfolder` ne rend
# plus le digest de la chaîne vide, et `date=True` prend la mtime de la cible
# au lieu de l'heure courante. C'est exactement l'empreinte dont ce dépôt a
# besoin : une empreinte de contenu qui échoue au lieu d'inventer.
#
# Et c'est devenu possible seulement maintenant : les seize paquets ai-helpers
# plafonnaient `os-helper<4`, donc demander la 4 rendait l'installation
# insoluble. Les seize sont republiés en `<5`, vérifié sur les métadonnées
# PUBLIÉES (pas sur le dépôt local ni sur l'éditable installé, qui m'ont
# trompé deux fois).
#
# Vérifié avant de l'écrire : cette machine exécute déjà le contrat 4.0.0 par
# un éditable, et les onze suites de la suite y sont vertes ; et un venv vierge
# résout `os-helper==4.0.0` avec audio 2.6.1, speaker 0.14.1, video 2.9.0,
# standpoint 0.13.1, best-engine 1.11.1, wallet 1.3.1 et elbow 0.4.1.
os-helper>=4.0.0,<5

# The caption auditor, and the only sibling whose absence silences a guard
# written here rather than in a brick.
#
# `tests/test_the_films_captions_pass_the_suites_own_auditor.py` measures the
# films' own WebVTT with `sprezzature_audio.audit_cues` — the same function the
# command line calls — and `tests/test_a_caption_track_is_what_the_rule_emits.py`
# re-emits each track through `sprezzature_audio.write_vtt` and compares the
# bytes. Both reach it through `pytest.importorskip`, so without this line they
# skip on a runner, and a skip reads exactly like a pass. That is the whole
# defect the 2026-10-31 caption work was about, one layer up: the tracks came
# into the clone so the audit could run in CI, and the audit would still not
# have run.
#
# It was light when added (1.5.0 brought four packages). Since the suite went
# to one `pip install` on 2026-11-01 the voices and NeMo are in its base, so
# this line is now the heavy one, and kept: the guards are worth it.
sprezzature-audio>=1.5.0

# The film guards a release of the films is held to — their claims against the
# code, the suite's own pitch checker, no retired voice engine — import
# sprezzature-video and skipped on every runner without it. It adds almost
# nothing to the line above, which it depends on.
sprezzature-video>=0.4.2

# The two film line-breaking guards measure advance widths in the site's own
# WOFF2 faces. fontTools reads WOFF2 only with Brotli, hence the extra. Without
# it the six checks skipped in CI ("could not import 'fontTools'") and failed
# in any venv that had fontTools through matplotlib but no Brotli.
fonttools[woff]>=4.40

# would, and fifteen of them compute their geometry with numpy — the map

# every generator imports for its fonts) does not then fall over on the
# arithmetic. Not a runtime dependency of anything this repository ships: the
# kits pin their own copy, `numpy==2.3.5`.
numpy>=1.24
