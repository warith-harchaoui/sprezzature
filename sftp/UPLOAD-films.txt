# Files the films deploy touches, relative to web/, as of 2026-10-28.
#
# web/video/ is not in git (see .gitignore), so a clone does not carry these
# and `git status` will never remind anyone they are pending. This list is the
# reminder.
#
# ELEVEN films, TWO languages, THREE canvases, all of them 4K. The landscape
# cut keeps the unsuffixed name because the home page, the Open Graph tags,
# the sitemap and the feed all point at it that way; the other two carry
# their canvas. So per film and language: three MP4s, three posters, and ONE
# WebVTT -- the three canvases are the same minute laid out differently and
# share their captions, because a second copy could only ever be the first
# one going stale.
#
# The two do not mix. A French film is French on screen, in the voice and in
# its subtitles; an English film is English throughout. That is why every
# name carries its language, and why there is no unsuffixed
# `sprezzature.mp4` any more.
#
# The host needs a video/ directory; fr/ already exists.
# Once uploaded, three checks say whether it landed:
#     curl -sI https://sprezzature.ai/video/sprezzature.fr.mp4 | head -1   -> 200
#     curl -sI https://sprezzature.ai/video/maps.en.portrait.mp4 | head -1 -> 200
#     curl -s https://sprezzature.ai/fr/films.html | grep -c '<track'      -> 11
#
# STILL ON THE SERVER and only removable by a delete there -- an upload cannot
# do it. The four films these replaced, and the unsuffixed English names:
#     figures-et-cartes.*  accessibilite.*  interface.*  moteur-local.*
#     sprezzature.mp4  sprezzature.jpg  ui.mp4  ui.jpg  cli-gui.mp4 ...
#     (every `<film>.mp4` and `<film>.jpg` without a language)
# Archived copies: brag-output/_retired/
#
# ABOUT 1.5 GB of MP4 in total, up from 260 MB: three canvases instead of one,
# and 3840x2160 instead of 1920x1080. That is the whole reason this list
# exists separately from the HTML -- the pages are small and the films are
# not, and a sync that treats them alike will sit there for an hour.
#
# `python3 brag-output/install_films.py` writes every one of these.
# `--only landscape` puts back just the cut the old deploy carried.
