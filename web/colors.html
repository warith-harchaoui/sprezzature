sprezzature-colors

Colors

Color tooling, make and audit: Web Content Accessibility Guidelines (WCAG) contrast with fixes in the perceptual OKLCH color space (Lightness, Chroma, Hue of the OKLab model), colour-vision-deficiency simulation, a curated palette, and a Tailwind config emitter. Deterministic: no model, no network.

SKILL.md (the agent spec) Give a ⭐️ on GitHub

Makes

  • A curated palette comma-separated values (CSV) file with semantic projections
  • A Tailwind theme.extend.colors config from the canonical palette
  • Perceptual lighten / darken on the OKLCH L axis

Audits

  • WCAG contrast audit with OKLCH-neighbour fix suggestions
  • Protanopia / deuteranopia / tritanopia simulation on screenshots

The skill triggers itself on phrasing like this, no command to memorize.
