    sprezzature-colors

    Couleurs

    Outillage couleur, make et audit : contraste selon les WCAG (Web Content Accessibility Guidelines, les règles internationales qui disent par exemple à quel point un texte doit contraster avec son fond) avec correctifs voisins dans l'espace colorimétrique perceptuel OKLCH (clarté, chroma et teinte du modèle OKLab), simulation des déficiences de vision des couleurs (CVD, color vision deficiency : voir mal certaines couleurs, souvent le rouge et le vert), une palette soignée et un émetteur de config Tailwind. Déterministe : sans modèle, sans réseau.

    SKILL.md (la spec agent) ⭐ sur GitHub

    Produit

    • Une palette au format valeurs séparées par des virgules (CSV) soignée avec projections sémantiques
    • Une config Tailwind theme.extend.colors depuis la palette canonique
    • Éclaircir / assombrir perceptuel sur l'axe L d'OKLCH

    Audite

    • Audit de contraste WCAG avec suggestions de correctifs OKLCH voisins
    • Simulation protanopie / deutéranopie / tritanopie sur captures d'écran

    La skill se déclenche sur une formulation de ce type, sans commande à mémoriser.

    Questions fréquentes

    Comment installer sprezzature-colors ?

    Lancez pip install sprezzature-colors (Python 3.10 ou plus récent) : une ligne installe les quatre outils, la ligne de commande, la simulation d'images, l'API (Application Programming Interface, la porte où frappent les autres programmes : un script envoie ses chiffres et reçoit une réponse) servie en HTTP (HyperText Transfer Protocol, le protocole par lequel un navigateur demande une page à un serveur) et le serveur MCP (Model Context Protocol, le protocole par lequel les agents IA appellent des outils en français), sans option à choisir. Pour s'en servir comme skill, pip install sprezzature puis sprezzature-skills --install (ou sprezzature-skills --install --agent opencode).

    Que fait sprezzature-colors ?

    sprezzature-colors a quatre outils : un audit de contraste WCAG d'une palette qui propose une couleur conforme pour chaque paire en échec, une simulation d'image telle que la voit une personne protanope, deutéranope ou tritanope (plus une version en niveaux de gris), une transposition de la palette à l'un de six niveaux d'accessibilité, et un export de la palette en configuration Tailwind. La porte d'entrée est sprezzature-colors, et chaque outil est aussi sa propre commande, comme sprezzature-colors-contrast ou sprezzature-colors-cvd.

    sprezzature-colors vérifie-t-il les couleurs de ma page web ?

    Non : sprezzature-colors audite les paires de couleurs d'une palette, un fichier JSON (JavaScript Object Notation, un format texte dans lequel les programmes rangent des données en champs nommés, comme « titre : Accueil ») dont les clés commencent par label-, brand- ou surface-, et simule le daltonisme sur une image, une capture d'écran par exemple ; il ne lit ni HTML ni CSS (Cascading Style Sheets, les feuilles de style qui disent au navigateur la couleur, la taille et la place de chaque élément). Le contraste d'une page rendue sur son vrai fond relève d'un outil qui pilote un navigateur, comme axe-core ou Lighthouse.

    En quoi sprezzature-colors diffère-t-il d'un vérificateur de contraste en ligne ?

    sprezzature-colors vérifie d'un coup toutes les paires d'une palette qui peuvent se côtoyer dans un thème (--all-pairs pour le produit croisé complet), au ratio fixé par --target, là où un vérificateur en ligne teste une couleur de texte et un fond saisis à la main. Pour chaque échec, il propose la couleur conforme la plus proche, de même teinte et même saturation, seulement plus claire ou plus foncée, et tourne hors ligne, dans un script ou une CI (continuous integration, l'intégration continue : un serveur relance les tests à chaque modification du code).

    sprezzature-colors envoie-t-il mes fichiers à un service cloud ou emploie-t-il l'IA ?

    Non : sprezzature-colors fait de l'arithmétique des couleurs déterministe, sans modèle d'IA ni accès au réseau, et n'a donc pas besoin d'Ollama ; la simulation écrit ses images sur votre disque, à côté de la source par défaut.

    Peut-on lancer sprezzature-colors en CI ?

    Oui : sprezzature-colors-contrast --palette palette.json sort avec le code 0 quand toutes les paires passent, 1 quand l'une échoue et 2 quand la palette ne donne aucune paire à vérifier, et --format json produit un rapport qu'une CI sait lire. Une API HTTP (POST /v1/contrast) fait la même vérification pour une chaîne écrite dans un autre langage.

    Peut-on utiliser sprezzature-colors sans Claude Code ?

    Oui : sprezzature-colors est une bibliothèque Python (import sprezzature_colors as sc), une ligne de commande, une API HTTP avec image Docker et un serveur MCP, sprezzature-colors-mcp, pour tout client MCP. L'image Docker lance ce serveur : un même port répond aux routes HTTP et à /mcp.

    sprezzature-colors est-il gratuit ?

    Oui : sprezzature-colors est open source sous licence BSD (Berkeley Software Distribution, une licence née à l'université de Berkeley : chacun peut réutiliser le code, même pour le vendre, en citant l'auteur), version 3-Clause, sans compte, sans clé d'API ni offre payante, et le code est sur GitHub.
