    sprezzature-colors

    Couleurs

    Outillage couleur, make et audit : contraste selon les règles WCAG pour l'accessibilité des contenus web avec correctifs voisins dans l'espace colorimétrique perceptuel OKLCH (clarté, chroma et teinte du modèle OKLab), simulation des déficiences de vision des couleurs, une palette soignée et un émetteur de config Tailwind. Déterministe : sans modèle, sans réseau.

    SKILL.md (la spec agent) ⭐️ sur GitHub

    Produit

    • Une palette au format valeurs séparées par des virgules (CSV) soignée avec projections sémantiques
    • Une config Tailwind theme.extend.colors depuis la palette canonique
    • Éclaircir / assombrir perceptuel sur l'axe L d'OKLCH

    Audite

    • Audit de contraste WCAG avec suggestions de correctifs OKLCH voisins
    • Simulation protanopie / deutéranopie / tritanopie sur captures d'écran

    Dites l'une de ces phrases

    La skill se déclenche sur une formulation de ce type, sans commande à mémoriser.

    audit de contraste ma palette est-elle accessible aperçu daltonien deutéranope / DVC éclaircis cette couleur OKLCH palette soignée palette vers tailwind sûr pour daltoniens
