    sprezzature-publish

    Publication

    Transforme un dossier de Markdown en site statique  : balises meta par page, un jeu complet de favicons / icônes d'application web progressive (PWA) depuis un logo, robots + sitemap + llms.txt + flux, réécritures en langage clair et narration en synthèse vocale (TTS) locale.

    SKILL.md (la spec agent) ⭐️ sur GitHub

    Produit

    • Open Graph (OG) + Twitter Card + Schema.org JSON-LD (JSON pour données liées) par page
    • Un jeu complet de favicons / icônes d'app / PWA depuis un logo, plus un webmanifest
    • robots.txt, sitemap.xml, llms.txt, Atom / flux Really Simple Syndication (RSS), humans.txt
    • Réécritures en langage clair et narration audio (MP3) via TTS libre (OSS) locale

    Audite

    • Linter le Markdown et détecter les liens cassés avant publication
    • Contrôles de lisibilité / niveau de lecture sur le texte

    Dites l'une de ces phrases

    La skill se déclenche sur une formulation de ce type, sans commande à mémoriser.

    markdown en site balises meta carte OG SEO GEO favicons robots.txt sitemap llms.txt flux Atom langage clair narre cet article lint markdown
