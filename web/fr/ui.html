sprezzature-ui

Génération d'interface utilisateur (UI)

UI vanilla JavaScript (JS) + Tailwind : composants, pages, formulaires, dialogues, tableaux de bord, pour les développeurs solo qui livrent des outils internes sans designer.

SKILL.md (la spec agent) ⭐️ sur GitHub

Produit

  • HTML (langage de balisage des pages web) sémantique + Tailwind : formulaires, modales, navigation, tableaux de bord, tables de données, réglages, états vides, squelettes
  • Variantes en mode sombre, anneaux de focus, garde-fous d'animation réduite par défaut
  • La règle des trois Roboto (sans + serif + mono), en respectant toute police que vous nommez
  • i18n extrait dans un seul fichier de configuration YAML partagé entre interface graphique (GUI) et prompts

Audite

  • Auditer une UI existante selon les conventions de sprezzature-ui et d'ergonomie
  • Auditer la couverture i18n et repérer les chaînes non traduites
