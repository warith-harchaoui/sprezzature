Lois de l'expérience utilisateur (UX)

Applique les Lois de l'UX canoniques (Jon Yablonski) au JavaScript (JS) standard + Tailwind : à la création d'interface utilisateur (UI) comme à l'audit de HTML (langage de balisage des pages web) existant. La référence couvre 30 lois avec déclencheur / action / hook Tailwind.

SKILL.md (la spec agent) ⭐️ sur GitHub

Produit

  • Concevoir un écran avec Hick / Fitts / Miller / Peak-End en tête
  • Chaque loi associée à un hook Tailwind concret

Audite

  • L'auditeur statique signale le sous-ensemble détectable mécaniquement : Hick, Miller, Fitts, Jakob, Tesler, Aesthetic-Usability, Attention sélective, Doherty, Choice Overload
  • Sévérité + sortie JSON (notation d'objets JavaScript) pour pré-commit / intégration continue (CI)
