Vision — texte alternatif

Rédaction de texte alternatif conforme au World Wide Web Consortium (W3C) via un modèle de vision Ollama local : arbre de décision par image, sortie dans toute langue détectée, mise en cache disque déterministe. Le seul modèle est qwen3-vl:8b. Rien ne quitte la machine.

En cours de développement : chaque sortie est un brouillon à relire, pas un texte alternatif définitif.

SKILL.md (la spec agent) ⭐️ sur GitHub

Produit

  • Brouillons d'alt pour images informatives / décoratives / fonctionnelles / texte / complexes / groupe
  • Sortie dans toute langue détectée, tournures natives pour les plus courantes
  • Biais par le texte environnant et le vocabulaire du projet
  • Un cache disque déterministe : la même image ne repasse jamais au modèle

Audite

  • Signale les images sans alt
  • Les brouillons sont des points de départ; vérifiez avant de valider (commit)

Dites l'une de ces phrases

La skill se déclenche sur une formulation de ce type, sans commande à mémoriser.

texte alternatif décris cette image brouillon d'alt description d'image img sans alt image décorative description de figure / graphique alt en lot
