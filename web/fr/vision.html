    Fusionné

    Vision fait maintenant partie d’Accessibility

    Le 17 octobre 2026, sprezzature-vision a cessé d’être une brique à part. Tout ce qu’elle faisait — rédiger des textes alternatifs conformes au W3C avec un modèle de vision local, l’arbre de décision par image, le cache sur disque — a rejoint sprezzature-accessibility.

    La raison : c’étaient deux moitiés d’un même travail, et personne n’en voulait une seule. Le lint dit qu’une page manque de texte alternatif ; le rédacteur l’écrit. Les garder séparées, c’était deux installations, deux skills se disputant les mêmes prompts, et un rédacteur incapable de voir la page qu’il décrivait — ce qui compte, puisque l’arbre de décision du W3C demande ce qu’une image fait sur la page : une question sur la page, pas sur les pixels.

    Cette page reste en place pour que le lien que vous avez suivi ne casse pas.
