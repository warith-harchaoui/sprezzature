Situation maps

An areas-of-control plate for any region, built as a layered Scalable Vector Graphics (SVG) the way a geopolitics desk would: bathymetry contours off the coast, classed pastel fills with white boundary casing, letter-spaced place labels, flashpoint markers, dual-unit scale bars, and a floating legend. One configuration file projects any country (auto-centred Lambert conformal conic). The same layers redraw for any conflict; below is Ukraine. Schematic, from open sources, not intelligence.

Real data: the last five French presidential runoffs

The same carefully authored SVG map engine, on real data from the French Ministère de l'Intérieur: the winner's second-round vote share by département across the last five presidential elections, on one frozen blue scale so the panels compare. 2002 (the republican sprezzature against the far right) is near-uniform; 2012 (the closest) is the palest; 2017 and 2022 show the lighter départements where Marine Le Pen ran strongest.
